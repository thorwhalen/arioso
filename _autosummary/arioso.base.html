arioso.base#

Core types and constants for arioso.

Defines the unified output types (Song, AudioResult) and the canonical set of affordance names that all platform adapters map to.

class arioso.base.AudioResult(audio_bytes=None, audio_url='', audio_array=None, sample_rate=0, format='', duration_seconds=0.0)[source]#

Bases: object

Unified audio output from any music generation platform.

Exactly one of audio_bytes, audio_url, or audio_array will typically be populated by the platform adapter. Conversion between forms can be done on demand by the caller.

audio_bytes#

Raw audio file bytes (MP3, WAV, etc.).

audio_url#

URL to download the audio file.

audio_array#

Numpy array of audio samples.

sample_rate#

Sample rate in Hz (e.g. 44100, 32000).

format#

Audio format string (e.g. “mp3”, “wav”, “pcm”).

duration_seconds#

Duration of the audio in seconds.
