# arioso.base

Core types and constants for arioso.

Defines the unified output types (Song, AudioResult) and the canonical
set of affordance names that all platform adapters map to.

### Classes

| [`Affordance`](#arioso.base.Affordance)(name, type, description[, default])   | Descriptor for a unified parameter affordance.           |
|---------------------------------------------------------------------------------------------------|----------------------------------------------------------|
| [`AudioResult`](#arioso.base.AudioResult)([audio_bytes, audio_url, ...])       | Unified audio output from any music generation platform. |
| [`Song`](#arioso.base.Song)([id, title, status, audio, metadata, ...])  | A generated song with its metadata and audio data.       |

### Exceptions

| [`CatalogMatchError`](#arioso.base.CatalogMatchError)(message, \*[, task_id, code])   | A platform refused the input audio because it matches a catalogued recording.   |
|----------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------|

### *class* arioso.base.AudioResult(audio_bytes=None, audio_url='', audio_array=None, sample_rate=0, format='', duration_seconds=0.0)

Bases: [`object`](https://docs.python.org/3/builtins/functions.html#object)

Unified audio output from any music generation platform.

Exactly one of audio_bytes, audio_url, or audio_array will typically
be populated by the platform adapter. Conversion between forms can
be done on demand by the caller.

Raw audio file bytes (MP3, WAV, etc.).

* **Type:**
  [`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)[[`bytes`](https://docs.python.org/3/builtins/stdtypes.html#bytes)]

#### audio_url

URL to download the audio file.

* **Type:**
  [`str`](https://docs.python.org/3/builtins/stdtypes.html#str)

#### audio_array

Numpy array of audio samples.

* **Type:**
  [`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)[[`Any`](https://docs.python.org/3/library/typing.html#typing.Any)]

#### sample_rate

Sample rate in Hz (e.g. 44100, 32000).

* **Type:**
  [`int`](https://docs.python.org/3/builtins/functions.html#int)

#### format

Audio format string (e.g. “mp3”, “wav”, “pcm”).

* **Type:**
  [`str`](https://docs.python.org/3/builtins/stdtypes.html#str)

#### duration_seconds

Duration of the audio in seconds.

* **Type:**
  [`float`](https://docs.python.org/3/builtins/functions.html#float)

### *exception* arioso.base.CatalogMatchError(message, , task_id=None, code=None)

Bases: [`RuntimeError`](https://docs.python.org/3/builtins/exceptions.html#RuntimeError)

A platform refused the input audio because it matches a catalogued recording.

This is a policy refusal (copyright filter), not a transient failure: callers
that retry or regenerate in a loop should treat it as final.

#### task_id

The provider task id of the refused generation, if known.

#### code

The provider’s error code (e.g. `413`), if given.
