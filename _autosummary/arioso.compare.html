arioso.compare#

Compare platforms on the same prompts: time, memory and objective checks, as records.

Choosing a local model is a measurement. compare() renders every prompt with every contender and yields one flat record per take: wall time (model load plus warm-up, then per take), real-time factor, peak memory, and objective checks of the audio (detected tempo against the BPM asked for, estimated key against the key asked for, clipping, level):

import arioso.compare as ac

records = list(ac.compare(["stable_audio_3", "magenta_rt", "ace_step:runtime=local"]))
ac.compare_page(records, "arioso_compare/index.html")

or, from the shell:

arioso compare stable_audio_3,magenta_rt,ace_step:runtime=local --prompts prompts.json

The records are the single source of truth: they are appended to <out_dir>/results.jsonl as they come, the command prints a summary of them, and compare_page() renders them as a page of players. Each contender runs in a fresh child process (see in_child_process()), one after the other, so only one model is in memory at a time and each one’s peak memory is its own.

A contender is a platform plus the options it is called with, written platform[:key=value[:key=value...]] (values are read as JSON when they parse, so num_steps=8 is an int): ace_step:runtime=local, musicgen:model=facebook/musicgen-small.

A prompt is a dict: text (required), id, and optionally bpm, key ("C major"), melody (an audio file, passed to platforms that take a melody) and duration. DFLT_PROMPTS is a small set covering a groove, an accompaniment and a loop.

Hosted platforms cost money per call, so compare() refuses them unless allow_hosted=True (is_hosted() says which those are).

Seams, all keyword arguments: runner (how one contender is run and measured: in_child_process() or in_this_process()), scorer (audio to a dict of checks: objective_checks()), and min_free_gb (refuse to start a contender when the machine has less memory available than that).

arioso.compare.compare(contenders, prompts=None, *, duration=10.0, seed=0, out_dir='arioso_compare', warmup=2.0, runner=None, scorer=<function objective_checks>, allow_hosted=False, min_free_gb=None, preload=(), timeout=None, run_id=None)[source]#

Render every prompt with every contender; yield one record per take.

Parameters:

  • contenders (str | Iterable[str | Contender]) – Platform specs ("ace_step:runtime=local", see Contender), comma-separated or as an iterable.

  • prompts – A JSON file, a list of prompt dicts, or None for DFLT_PROMPTS.

  • duration (float) – Seconds asked of each take (a prompt’s own duration wins).

  • seed (Optional[int]) – Passed to platforms that take one (None: don’t).

  • out_dir (str | PathLike) – Takes go to <out_dir>/<run_id>/<contender>/<prompt id>.wav; records are appended to <out_dir>/results.jsonl (one file for every run).

  • warmup (Optional[float]) – Seconds generated once per contender before the timed takes (0/None: no warm-up, so the first take’s time includes loading the model).

  • runner (Optional[Callable[..., list[dict]]]) – Runs one contender: in_child_process() (None, the default) or in_this_process(), or any callable with their signature.

  • scorer (Optional[Callable[[Any, int, Mapping], dict]]) – (audio, sample_rate, prompt) -> dict merged into each record; None for no checks.

  • allow_hosted (bool) – Allow contenders that call paid hosted services (is_hosted()).

  • min_free_gb (Optional[float]) – When the machine has less memory available than this before a contender starts, record that contender as an error instead of running it.

  • preload (Iterable[str]) – Modules ("module" or "module:function") that make third-party platforms known, run here before anything is checked and passed to a runner that takes preload (the child process runs them too).

  • timeout (Optional[float]) – Seconds a contender may run before it is killed with every process it started, passed to a runner that takes timeout (the default one does).

  • run_id (Optional[str]) – Names this run in its records and its folder (default: the start time).

Yields:

Flat dicts – contender, platform, options, prompt, timings (load_s, gen_s, rtf), memory (peak_memory_gb, workers_peak_memory_gb, available_memory_gb), path, the scorer’s checks, error when a take failed, and the machine.

arioso.compare.in_child_process(contender, prompts, *, duration, seed, out_dir, warmup, python=None, preload=(), timeout=None)[source]#

Run contender in a fresh python -m arioso.compare process (the default runner).

A fresh process per contender frees the previous model’s memory before the next loads, and makes the process’s lifetime peak memory that contender’s own. python is the interpreter (default: this one); preload names what the child runs first, to make third-party platforms known: "module" is imported, "module:function" is imported and function() called. The child’s output goes to <out_dir>/<contender>/child.log. The child writes each take’s record as soon as it is made, so a child killed after timeout seconds (with every process it started) or exiting non-zero still returns the takes it finished, each marked with child_exit; prompts it never reached get an error.

Return type:

list[dict]

arioso.compare.in_this_process(contender, prompts, *, duration, seed, out_dir, warmup, on_record=None)[source]#

Run contender on prompts here; one record per prompt, audio under out_dir.

A take that fails becomes a record with an error (the others still run); a contender that fails its warm-up makes every record an error. peak_memory_gb is this process’s lifetime peak, so run each contender in a fresh process (in_child_process()) to attribute it; workers_peak_memory_gb is the peak of the processes it started (a local runtime’s worker, or one process per take), sampled while it ran (see PeakSampler; here its exit-time floor also covers children of earlier contenders run in this process). on_record is called with each take’s record as soon as it is made, before the memory figures are added at the end.

Return type:

list[dict]

arioso.compare.is_hosted(contender)[source]#

Whether a contender may call a hosted (paid, per call) service rather than a local model.

Errs on the side of caution. Local means: access_type is python_lib or local_runtime (a missing one is the translation layer’s rest_api), the terms are not the provider’s, no credential is taken (even an optional one: yue calls fal.ai whenever FAL_KEY is set), and no fal model is declared. Anything else is hosted, unless the contender asks for runtime="local" and the platform declares a local runtime (ace_step); on any other platform that option is ignored, so it changes nothing here either.

>>> is_hosted("elevenlabs"), is_hosted("stable_audio_3"), is_hosted("ace_step:runtime=local")
(True, False, False)
>>> is_hosted("elevenlabs:runtime=local")
True
