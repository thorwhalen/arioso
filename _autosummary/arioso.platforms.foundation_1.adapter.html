arioso.platforms.foundation_1.adapter#

Foundation-1 adapter: stable-audio-tools in its own environment, one worker per adapter.

The model loads once, in a Worker running arioso/_workers/foundation_1_worker.py with the Python of the foundation-1 environment, which ensure_env() builds on first use (pinned stable-audio-tools, torch 2.7). make_worker= and ensure_env= are the seams.

Foundation-1 reads a tag prompt: instrument family and sub-family, timbre, notation and FX tags, then "<N> Bars, <BPM> BPM, <key>" (see build_prompt()). arioso’s bpm and key become those tags; a loop’s length follows from its bars and tempo, so with a tempo the clip is exactly bars bars of 4/4 (bars= 4 or 8, else the count nearest to duration). Without one, duration is the clip length (a one-shot or free clip).

generate(prompt, *, duration=None, bpm=None, key=None, bars=None, note=None, model='foundation-1', num_steps=100, guidance=7.0, seed=None, negative_prompt=None, sampler='dpmpp-3m-sde', device=None, normalize=True, **kwargs)[source]#

Render a loop or a one-shot for the tag prompt prompt.

Parameters:

  • prompt (str) – Foundation-1 tags, e.g. "Synth Lead, Warm, Arp, Medium Reverb" (instrument, timbre, notation, FX; see the model card). Passed through, with the bar, tempo and key tags appended when given as arguments.

  • duration (float) – Seconds; without a tempo, the clip length (default 10), with one, only the hint for the bar count.

  • bpm (float) – Tempo, appended as "<bpm> BPM" (trained on 100-150, see the config).

  • key (str) – Key, appended as e.g. "E minor" ("Em" and "E minor" both work).

  • bars (int) – 4 or 8, with a tempo: the loop is exactly that many 4/4 bars.

  • note (str) – A one-shot’s pitch ("C3"), appended as "Target Note, C3"; with model="1.2-keybeds" the prompt takes that checkpoint’s single-note form ("Keybed, Timbre Profile, ..."). Default length 3 s.

  • model (str) – "foundation-1" (loops), "1.2-samples" (loops and one-shots) or "1.2-keybeds" (pitch-consistent one-shots).

  • num_steps (int) – Sampler steps.

  • guidance (float) – CFG scale.

  • seed (int) – Seed; a fresh one is drawn and recorded when None.

  • negative_prompt (str) – What to steer away from.

  • sampler (str) – stable-audio-tools sampler type.

  • device (str) – "mps", "cuda" or "cpu"; default: the best available.

  • normalize (bool) – Scale the take to full scale (its peak at 0 dBFS). False keeps the model’s own level (written as float, so nothing clips): takes meant to sit side by side, such as a keybed’s chunks, keep their balance.

Returns:

A complete Song (44.1 kHz stereo wav), the prompt sent in its metadata.

arioso.platforms.foundation_1.adapter.build_prompt(prompt, *, bpm=None, key=None, bars=None, duration=None, note=None, keybed=False, supported_bars=(4, 8))[source]#

The tag prompt, the clip’s seconds and the timing it used, from arioso’s controls.

Tags already in prompt are read and must agree with the arguments ("140 BPM" with bpm=120 is an error; keys compare by pitch class and mode, so "Cb major" agrees with "B major"); a short key tag ("Am") is spelt out. Missing tags go in the model card’s order, ..., 8 Bars, 140 BPM, E minor: bars before the tempo (also when only the tempo was in the prompt), the key last.

With a tempo (bpm or a BPM tag) the clip is bars bars of 4/4: bars, else a Bars tag, else the supported count nearest to duration * bpm / 240 (4 without a duration); a duration more than a bar away from that warns. Without a tempo the clip is duration seconds (default 10).

note makes a one-shot at that pitch: "Target Note, <note>" is appended (no tempo or bars then; default length 3 s; a key goes before it; a Target Note already in the prompt is read like the other tags), and with keybed=True (the keybeds checkpoint) the prompt starts with its single-note prefix "Keybed, Timbre Profile".

>>> build_prompt("Synth Lead, Warm, Arp", bpm=140, key="Em", duration=12)
('Synth Lead, Warm, Arp, 8 Bars, 140 BPM, E minor', 13.714285714285714, {'bpm': 140, 'bars': 8, 'key': 'E minor', 'note': None})
>>> build_prompt("Grand Piano, Bright", note="c3", keybed=True)[:2]
('Keybed, Timbre Profile, Grand Piano, Bright, Target Note, C3', 3.0)
