arioso.platforms.musicgen.backends#

The two ways to run MusicGen, behind one interface (thorwhalen/arioso#31).

The adapter holds the modes (text, melody, continuation: window checks, chaining, splicing); a backend holds what one library needs to load a model and run it in each of them. audiocraft is Meta’s library, transformers the HuggingFace port the adapter falls back to. Each backend wraps a model that is already loaded, so building one is free; load is what loads one.

Both return the model’s own output layout for text and melody, (channels, frames) from audiocraft and (frames,) from transformers’ first channel, and mono for a continuation.
