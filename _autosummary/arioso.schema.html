arioso.schema#

Machine-readable parameter schemas: what each platform accepts, as JSON Schema.

A front end, an agent or a form generator needs more than the parameter names: it needs each parameter’s type, its bounds or choices, a display title and whether it is shared across platforms. param_schema() assembles that from the two places arioso already keeps it, so nothing is restated:

  • common parameters are the unified affordances (arioso.base.AFFORDANCES) a platform lists in supported_affordances; their type, description and bounds come from the affordance, overridden by the platform’s param_map entry (title, description, minimum/min, maximum/max, choices, default, type).

  • extra parameters are the platform’s own adapter_params. A platform may declare them as a dict of name to spec (the same keys as a param_map entry, type being a Python type); a bare list of names is still accepted, and such extras are marked untyped so a form can leave them out.

native_default is never used as a default: it is in the platform’s units (milliseconds, a noise level), not the unified ones. A unified default is the default key.

Example:

>>> schema = param_schema("sunoapi")
>>> schema["properties"]["weirdness"]["x-arioso"]["group"]
'extra'
>>> schema["properties"]["audio_input_strength"]["maximum"]
1

Module Attributes

AUDIO_AFFORDANCES

Affordances whose value is audio (a file, bytes, a waveform), not a scalar.

MECHANICS_AFFORDANCES

Affordances that steer the call rather than the music; left out of schemas.

OPERATION_AFFORDANCES

Operations a platform supports, from the affordance that enables each.

MECHANICS_EXTRAS

Extras that steer the call (transport, process, device), not the music; left out of schemas.

arioso.schema.param_schema(platform)[source]#

The JSON Schema (draft 2020-12) of the parameters platform accepts.

Each property carries x-arioso.group: "common" for a unified affordance (the same name on every platform that has it) or "extra" for a parameter only this platform has. The schema’s own x-arioso lists both groups and the platform’s operations. Reads the config only, so no adapter or optional dependency is loaded.

Parameters:

platform (str) – Platform identifier (see arioso.list_platforms()).

Return type:

dict

Returns:

A JSON-ready dict.
