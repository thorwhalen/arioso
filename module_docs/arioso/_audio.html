arioso._audio

Audio-input normalization for the enhance / audio-conditioning stage.

The facade’s arioso.enhance() and the audio-accepting adapters (stable_audio, musicgen melody, udio …) each want the input audio in a slightly different concrete form – a file path, a NumPy waveform, or a torch tensor. This module is the single ingress: to_audio_ref() accepts any of the forms a caller is likely to have and returns an AudioRef whose lazy accessors produce whichever form an adapter needs.

Accepted inputs (see to_audio_ref()):

  • a generated Song or AudioResult

  • raw encoded audio bytes (e.g. MP3/WAV file contents)

  • a filesystem path as str or pathlib.Path

  • a NumPy waveform paired with its rate as (array, sample_rate)

  • a bare NumPy waveform (sample rate must then be supplied out of band)

All heavy dependencies (numpy, soundfile, torch) are imported lazily, so import arioso never requires them; a precise ImportError is raised only if a conversion that needs one is actually requested.

class arioso._audio.AudioRef(*, path: str | None = None, data: bytes | None = None, array: Any = None, sample_rate: int | None = None)[source]

A lazy, format-agnostic handle to a piece of audio.

Construct it via to_audio_ref() rather than directly. Exactly one of path / data / array describes the source; sample_rate is known immediately for array/tuple sources and decoded on demand otherwise. The accessors (as_array(), as_path(), as_waveform()) produce the requested concrete form, converting (and caching) as needed.

as_array()[source]

Return the waveform as a NumPy array (shape (frames, channels)).

Decodes path / data via soundfile on first call and caches the result (and the discovered sample rate).

as_path(*, suffix: str = '.wav') → str[source]

Return a filesystem path to the audio (writing a temp WAV if needed).

Adapters that shell out or upload a file (e.g. udio, yue) use this. A temp file created here is tracked and removed by cleanup().

as_waveform()[source]

Return the audio as a torch tensor of shape (channels, frames).

This is the form neural backends want (stable_audio’s initial_audio_waveforms, musicgen melody chroma). Mono audio is returned as (1, frames).

cleanup() → None[source]

Remove any temp file this ref created via as_path().

property sample_rate: int

The audio sample rate in Hz (decoding a header if necessary).

arioso._audio.to_audio_ref(value: Any) → AudioRef[source]

Normalize any supported audio input into an AudioRef.

Parameters:

value – One of an AudioRef (returned as-is), a Song, an AudioResult, raw encoded bytes, a str/Path file path, an (array, sample_rate) pair, or a bare NumPy waveform array.

Returns:

An AudioRef wrapping the input.

Raises:

  • TypeError – If value is not a supported audio input form.

  • ValueError – If a Song/AudioResult carries only a remote audio_url (fetch it first with arioso.fetch_audio()).
